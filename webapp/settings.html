📋 Templates

    Dictation

    No findings or reports are stored. Only templates & these settings live in this browser's localStorage. The offline engine requires the free whisper.cpp server running on the same machine (see README).

    🖨 Report formatting (Word style)

    Applies to the on-screen report and to the rich text placed on the clipboard, so a paste into the PACS/RIS keeps the look. Formatting is set per section; any finding dictated later inherits its section's format automatically.
